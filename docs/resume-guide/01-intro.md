# Start with the hiring decision

A resume is evidence for one hiring decision. Before editing, write down the target profession, level, and the problems the role is expected to solve.

Read the job description in three passes:

1. Mark explicit requirements that appear essential.
2. Note repeated responsibilities, tools, customers, and outcomes.
3. Separate preferences from requirements.

Build a small evidence list beside those notes. A requirement is supported only when your work history, education, project record, or verified training demonstrates it. Leave unsupported terms out. A visible gap is safer than a false claim.

The first page should answer four questions quickly: What do you do? At what level? Which results prove it? Which experience is most relevant here?

Do not write one resume for every possible role. Keep a factual source profile, then create a copy for each serious application. Tailoring means choosing and ordering true evidence. It does not mean changing dates, titles, employers, metrics, or scope.
