# Keep contact details simple

Put contact information in the document body near your name:

- professional email address;
- phone number with country code when applying internationally;
- city and country or region;
- portfolio or professional profile when relevant.

Use ordinary linked text. Icons can disappear during text extraction, and contact details in a PDF header may be skipped by some systems.

You usually do not need a street address, date of birth, marital status, national ID, or photograph. Local laws and hiring customs vary, so check the expectations of the market you are entering.

Test every link. Use the public URL a reviewer can open, not an editing link or a private dashboard. Designers should label the portfolio clearly. Developers can include a code profile only when it represents their current work.
