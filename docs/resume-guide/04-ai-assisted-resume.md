# Use AI without inventing facts

AI can help compare a resume with a job description, find repetition, and test alternate wording. It cannot decide which claims are true.

Give an assistant three inputs:

1. the factual source resume;
2. the full job description;
3. a rule that every claim must be supported by the source.

Ask for a requirement-to-evidence table before asking for rewritten bullets. Mark each requirement as supported, partial, or a gap. Review the table yourself.

A useful editing prompt is:

> Rewrite this bullet for clarity and relevance. Preserve every fact, number, title, date, technology, and scope. Do not add inferred results. If the result is missing, suggest a question I can answer instead of inventing one.

Check the output for inflated ownership, invented numbers, borrowed keywords, and vague praise. Read it aloud. Replace stock phrases with direct language that sounds like you.

Never paste private employer data, customer records, unreleased metrics, or personal identifiers into a service unless its data policy and your obligations allow it.
